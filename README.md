### Алгоритм:
1. Начало
2. Объявить переменные:
- **x** — первая переменная.
- **y** — вторая переменная.
- **d** — константа, значение которой равно `1`.
Функция задана следующим выражением:

\[
F(x,y) = \frac{\cos^3(y) + 2^x \cdot d}
{e^y + \ln(\sin^2(x) + 7.4)}
\]

Значение константы:

```text
d = 1
```
3. Составить условие при помощи операторов if и else.
Для вычисления значения функции необходимо ввести значения `x` и `y`, после чего программа вычисляет значение функции.
Перед вычислением проверяется возможность выполнения выражения:

```text
sin²(x) + 7.4 > 0
```

Если условие выполняется, программа вычисляет значение функции.
Если условие не выполняется, выводится сообщение об ошибке.
4. Конец.

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    double x, y;
    double d = 1.0;
    double F;

    puts("Введите значение x:");
    scanf("%lf", &x);

    puts("Введите значение y:");
    scanf("%lf", &y);

    if (sin(x) * sin(x) + 7.4 > 0)
    {
        F = (pow(cos(y), 3) + pow(2, x) * d) /
            (exp(y) + log(sin(x) * sin(x) + 7.4));

        printf("F(x, y) = %.6f\n", F);
    }
    else
    {
        puts("Ошибка: невозможно вычислить натуральный логарифм.");
    }

    return 0;
}
```
